
# How to show code in viva

1. Open GitHub repo in browser and show:
   - app/api/recipe/route.js (AI integration)
   - app/page.jsx (Frontend)
   - components/RecipeCard.jsx
   - package.json and .gitignore

2. Explain .env usage and never show API keys.

3. If asked to run, open terminal and run `npm run dev` and demonstrate a sample request.

4. If asked line-by-line, focus on:
   - prompt construction
   - fetch to OpenAI
   - returning JSON to frontend
